 RAID PANEL  作者用セットアップガイド
 （鳴瀬碧衣が1回だけやる作業。ライバーには不要）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

このフォルダに入っているもの
─────────────────────────────────────────────
 index.html            … ツール本体。これ1つで画面も処理も全部入っている
 config.js             … 設定ファイル。Client ID を書くのはここだけ
 セットアップ_作者用.txt  … いま読んでいるファイル
 つかいかた_ライバー用.txt … ライバーに渡す説明書
 README.md             … 技術メモ（読まなくても運用できる）


 やることは3つだけです。
 STEP 01  Twitchアプリを登録して Client ID をもらう
 STEP 02  config.js に貼る
 STEP 03  GitHub Pages に置いてURLを配る


━━━ STEP 01  Twitchアプリを登録する ━━━━━━━━━━━━━

 1. https://dev.twitch.tv/console/apps を開く
 2. 右上の「アプリケーションを登録」を押す
 3. 次のように入力する

    名前            MEDISIA RAID PANEL
                    ※Twitch全体で重複しない名前が必要。
                      弾かれたら末尾に数字を足す

    OAuthリダイレクトURL
                    STEP 03 で決まる公開URLを入れる。
                    まだ決まっていないので、いったん
                      http://localhost
                    だけ入れて先に進み、STEP 03 のあとで戻ってきて
                    正しいURLを追加する

    カテゴリー      Broadcasting Suite

    クライアントタイプ
                    公開 (Public)
                    ★ここを「機密」にすると動きません。必ず「公開」。

 4. 「作成」を押し、一覧から作ったアプリの「管理」を開く
 5. 「クライアントID」の文字列をコピーする
    （クライアントシークレットは使いません。発行しなくてOK）


━━━ STEP 02  config.js に貼る ━━━━━━━━━━━━━━━━━

 config.js をメモ帳で開き、1行目のカッコの中に貼る。

   CLIENT_ID: "",
              ↓
   CLIENT_ID: "ここにコピーした文字列",

 ダブルクォート " " を消さないこと。
 他の項目は触らなくて構いません。


━━━ STEP 03  GitHub Pages に置く ━━━━━━━━━━━━━━━

 1. https://github.com/new で新しいリポジトリを作る
      Repository name : raid-panel
      Public を選ぶ（Privateだと Pages が使えません）
 2. できた画面の「uploading an existing file」をクリックし、
      index.html  と  config.js  の2つをドラッグして
      「Commit changes」を押す
 3. 上のタブの Settings → 左メニューの Pages を開く
 4. Source を「Deploy from a branch」、Branch を「main」「/(root)」にして Save
 5. 1〜3分待ってページを再読み込みすると、上に公開URLが出る
      例）https://naruse-aoi.github.io/raid-panel/

 6. ★STEP 01 に戻り、アプリの管理画面で
    「OAuthリダイレクトURL」に次の2つを登録して保存する。

      https://naruse-aoi.github.io/raid-panel/
      https://naruse-aoi.github.io/raid-panel/index.html

    2つとも登録しておくのがコツです。
    ライバーがどちらの形でURLを開いてもログインできるようになります。
    ここが1文字でも違うと「redirect_mismatch」で弾かれます。

 7. 自分でそのURLを開き、
    チャンネル名を入れて「チャット監視を開始」→ ランプが緑
    「Twitchでログイン」→ 許可 → 右上に自分のIDが出る
    ここまで確認できたら完了です。


━━━ 更新のしかた ━━━━━━━━━━━━━━━━━━━━━━━━━

 index.html を直したら、GitHubの同じ画面で
 「Add file → Upload files」から上書きアップロードするだけ。
 URLは変わらないので、ライバーへの再案内は不要です。

 レイドが来たときに、相手の配信リンクを自分だけ見られて
 シャウトアウトも自動で飛ぶパネルを用意しました。

 ▼ここを開くだけです（インストール不要）
 https://naruse-aoi.github.io/raid-panel/

 【最初の1回だけ】
 1. 「監視するチャンネル名」に自分のTwitch ID（英数字のほう）を入れて
    「チャット監視を開始」を押す
 2. 「Twitchでログイン」を押して、出てくる画面で「許可」を押す
 → 以上です。次からはURLを開くだけで設定が残っています。

 【使い方】
 配信中はこのページをサブモニタで開きっぱなしにしてください。
 レイドが来ると相手の名前・配信タイトル・リンクが出て、
 公式シャウトアウトが自動で飛びます。
